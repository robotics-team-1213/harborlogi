사람의 로그인과 서비스 권한은 어떻게 연결되나요?
Harbor 사용자
팀 계정으로 업무를 결정합니다. Harbor가 역할과 확정 이력을 관리합니다.
Harbor 서비스 신원
Fleet이 발급한 전용 service 역할로 API를 호출합니다. 사람의 비밀번호·세션을 전달하지 않습니다.
Fleet·ROSY
각 요청의 자격·소유 범위와 설치·자원·안전 조건을 검증합니다. Harbor 역할이 Fleet 권한으로 바뀌지 않습니다.

연결 검사와 실제 API 호출은 같은 서비스 신원·역할을 확인합니다. Fleet 콘솔은 별도로 로그인합니다. 토큰은 링크나 브라우저에 전달하지 않으며, 작업 receipt를 Harbor 업무 완료로 바로 바꾸지 않습니다.
