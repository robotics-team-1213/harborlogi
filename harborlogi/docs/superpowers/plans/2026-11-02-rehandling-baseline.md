# 재취급 기준 결과 확보

목표: 팀 main의 기존 R1 계획기를 수정하지 않고, 회수 순서 정보 유무에 따른 연속 반출의 논리 이동 수와 계획 계산 시간을 비교한다.

범위: 표준 라이브러리와 기존 계획기만 사용한다. 실물 명령·API·DB·자동 승인에는 연결하지 않는다. 전체 작업 시간은 측정하지 않았으므로 null로 명시한다.

- [x] `tests/test_rehandling_baseline.py`: 연속 반출의 집계, HOLD 유지, 입력 불변성과 비교 쌍의 동일성을 검증한다.
- [x] `tools/rehandling_baseline.py`: 고정된 가로/세로 배치와 두 회수 순서를 순서 정보 없음/있음으로 비교한다. 매 반출 뒤 합성 반출대를 비우며 이는 실물 완료 근거가 아니다.
- [x] 관련 시험과 전체 unittest를 실행하고 JSON 결과 및 검증 기록을 남긴다.
- [x] 보정·하중의 기존 코드와 수용 기록에서 확인된 사실과 미확인 항목을 구분한다.

실험 단위는 4개 고정 배치/순서 조합이다. 반복은 계산 시간 관측용이며 독립 표본으로 세지 않는다. 처리 순서는 반복마다 교대한다. READY/HOLD, 탐색 한도와 실패를 숨기지 않는다. HOLD면 이후 회수는 실행하지 않고 완료 여부를 false로 남긴다. 실물 효과나 일반적인 성능 우위는 주장하지 않는다.
