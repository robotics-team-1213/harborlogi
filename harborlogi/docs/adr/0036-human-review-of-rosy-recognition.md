# ADR 0036: ROSY 인식 차이는 사람이 비교·판정하며 반입부터 연결한다

날짜: 2026-11-21

상태: **제안(초안), UI 미구현**. 반입의 기존 계약부터 연결하고, 자리별 인식 판정은 ADR0032 계약 수용 뒤로 미룬다.

연결: [반입 ADR0029](0029-port-events-and-intake-identity.md), [기명 확인 ADR0023](0023-human-attested-evidence.md), [자리별 계약 ADR0032](0032-per-slot-rosy-recognition-contract.md), [출발 ADR0033](0033-departure-release-rosy-first-field-fallback.md). 다른 0029(알림 outbox)와 혼동하지 않는다.

## 배경

시안에는 Harbor 평면과 ROSY 탑뷰를 나란히 보고 사람이 기록·인식·직접 입력 중 고르는 팝업이 있다. 실제로는 반입 사건 신원과 카메라 프레임 경로는 있지만 자리별 인식·장부 수정·되돌리기 계약은 없다. 사진만으로 어느 자리의 어떤 화물인지 자동 확정할 수 없다.

## 결정 제안

1. 첫 범위는 `harbor/port_events.py`의 반입 보류·확인 대기다. **엄밀한 `HOLD`와 `UNREADABLE` 확인 대기는 구분한다.** 현재 `UNREADABLE`은 attention으로 남으며 HOLD 상태가 아니다. 보류 목록을 UI에 연결할 때 양쪽을 빠뜨리지 않도록 실제 조회 인터페이스를 확인한다. `HARBOR_LEDGER_PATH`가 없으면 「연동 전」이며 예시 건수를 채우지 않는다.
2. 같은 화면에서 비교 팝업을 연다. 왼쪽 Harbor 평면과 대상·선언 화물, 오른쪽 실제 카메라 프레임과 시각을 보여 준다. 프레임 없음·오래됨·자리 대응 불명은 그대로 알린다. 자리 대응 없는 프레임에 가짜 확대·인식 표식을 붙이지 않는다. 사진은 신원 판정을 대신하지 않는다.
3. 첫 구현에서 쓰기는 **UNREADABLE의 기명 반입 확인만** 기존 `attest_received(object_ref, attested_by, now)`로 연결한다. 로그인한 운영 역할이 대상 화물을 실제 반입점에서 확인했음을 제출한다. 확인자·대상·시각은 서버가 결속하고 현재 상태·권한을 다시 검증한다. 현재 도메인 메서드는 UI보다 넓으므로 서버에서 UNREADABLE 조건을 제한해야 한다. 관리·조회·현장은 이 인식 판정 폼에서 보기만 한다. 현장의 기존 적재면·실행 단계 확인 권한과는 별개다.
4. `MISMATCH`·`LOST`·`DAMAGED`는 사유와 근거를 보기만 한다. 「ROSY가 맞음」이나 새 번호 입력으로 장부를 덮어쓰거나 보류를 해제하지 않는다. 확인 기록은 자동 인식과 구분하며 원래 사건·사진·판독값을 보존한다. 반입 확인이 장치 실행·업무 완료·차량 출발 허가를 뜻하지 않는다.
5. 자리별 비교는 ADR0032의 주소·시각·revision·신원·프레임 접근 계약이 수용된 뒤다. 그 전에는 자리별 차이 표식과 「야드와 다른 곳 N」을 끈다. 장부를 혼자 바꾸지 않는다. API 경로·필드를 추가로 지어내지 않는다.
6. 이후 자리별 「Harbor 기록이 맞음 / ROSY 인식이 맞음 / 둘 다 아님」, 빈 자리·추가 화물·직접 입력·되돌리기는 별도 쓰기 계약이 필요하다. 중복 화물·지지층·낡은 계획 재검토·후속 변경 충돌·불변 감사 기록·기명 판정 보존까지 정한 뒤 연다. 시안의 인메모리 수정 기능을 운영 계약으로 삼지 않는다.

## 수용 조건

반입 목록의 보류와 못 읽음, 연결 없음, 관리·조회·현장 POST 거절, 운영의 UNREADABLE만 허용, 상태 변경 후 제출 거절, 원래 사건 보존을 시험한다. 모달은 넓으면 두 화면 나란히·좁으면 위아래이며, 키보드 포커스를 가두고 Esc·닫기·취소 뒤 원래 버튼으로 돌려준다. 확정으로 버튼이 없어지면 남은 목록이나 처리 결과로 돌려준다. 닫기·화면 새로고침을 판정 완료로 저장하지 않는다.

## 사람이 정할 것

자리별 판정을 저장·수정할 주체와 권한, 프레임 접근·자리 대응·신선도 기준, 수정에 따른 계획 무효화와 되돌리기 계약. 이 항목들은 ADR0032 이후이며 첫 반입 UI의 범위에 넣지 않는다. 화면 전체 목표는 [설계35](../design/35-control-dashboard.md)다.
